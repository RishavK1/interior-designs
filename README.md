# Allure Designs by Palak — Website Concept

A responsive interior design studio homepage concept built with Next.js, React, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

This is an independent design concept. The imagery is illustrative, and the website is not an official site or a representation of confirmed services, projects, or endorsements by Allure Designs by Palak.
